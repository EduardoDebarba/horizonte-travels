# Horizonte Viagens

Landing page premium para uma agência de viagens especializada em experiências personalizadas, roteiros exclusivos e destinos nacionais e internacionais.

## Site publicado

Acesse o projeto no GitHub Pages:

[https://eduardodebarba.github.io/horizonte-travels/](https://eduardodebarba.github.io/horizonte-travels/)

## Sobre o projeto

A Horizonte Viagens apresenta uma experiência editorial, sofisticada e responsiva para inspirar visitantes a explorar destinos, conhecer roteiros selecionados e solicitar uma viagem sob medida.

O site foi desenvolvido com foco em:

- fotografia imersiva;
- identidade visual premium;
- navegação responsiva;
- modais de roteiros e revista;
- formulário de solicitação de viagem;
- microinterações e animações sutis;
- publicação via GitHub Pages.

## Tecnologias

- React
- TypeScript
- Vinext
- Tailwind CSS
- Lucide React
- GitHub Actions
- GitHub Pages

## Como rodar localmente

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

Depois acesse:

[http://localhost:3000](http://localhost:3000)

## Build

Para gerar a versão de produção:

```bash
npm run build
```

## Deploy

O deploy para o GitHub Pages é feito automaticamente pelo GitHub Actions a cada push na branch `main`.

O projeto está configurado para publicar a versão estática em:

[https://eduardodebarba.github.io/horizonte-travels/](https://eduardodebarba.github.io/horizonte-travels/)
